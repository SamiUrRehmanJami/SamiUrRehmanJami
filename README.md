### 🚀 About Me

5+ years building production SaaS platforms, marketplaces, and AI-powered products that real users rely on every day.

I'm a Senior Full-Stack Engineer specializing in the **MERN** (MongoDB · Express · React · Node.js) and **MEAN** (MongoDB · Express · Angular · Node.js) stacks. I've shipped complete web applications — from architecture to deployment — for US-based B2B platforms and AI SaaS products used across multiple markets.

Currently at **SeeBiz**, I build and own features across three production platforms — a B2B wholesale marketplace, an AI SaaS platform with LLM-driven features, and an intelligent SaaS product with RAG pipelines for context-aware AI.

- 🔭 End-to-end ownership — I take an idea from whiteboard to production
- 🧠 AI integration — LLM APIs, RAG pipelines, OpenAI — turning AI from a demo into a working product
- ⚡ Performance-focused — Redis caching, Elasticsearch, scalable REST APIs
- 🌍 Remote-first mindset — 5+ years collaborating with US teams across time zones

**SeeBiz — B2B Wholesale Marketplace**

`Angular` `Node.js` `MongoDB` `Redis` `Elasticsearch`

**Krub.ai — AI-Powered SaaS Platform**
AI-driven SaaS product built with Next.js, Node.js, and TypeScript, integrating the OpenAI API to power community features — prompt design, API integration, and the frontend experience around it.
`Next.js` `Node.js` `TypeScript` `OpenAI API`

**Turnfeat Ai — Intelligent SaaS Platform**
Intelligent SaaS product built with React, Node.js, and PostgreSQL, implementing RAG pipelines and LLM integrations for context-aware AI features.
`React` `Node.js` `PostgreSQL` `RAG`

`Next.js` `React` `Node.js`
